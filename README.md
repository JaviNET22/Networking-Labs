# Networking Labs

Colección de laboratorios prácticos de redes que diseño y construyo por mi cuenta para afianzar conceptos y practicar configuración de equipos de red. Cada laboratorio es autocontenido y se centra en un tema concreto.

> **Estado:** repositorio en crecimiento. Voy añadiendo nuevos laboratorios de forma periódica.

---

## Sobre mí

Soy ingeniero de redes en formación, con interés en infraestructura de data center y automatización de redes con Python (Napalm, Netmiko, asyncio). Este repositorio recoge la parte más práctica de mi aprendizaje: montar topologías, configurarlas y entender por qué funcionan.
